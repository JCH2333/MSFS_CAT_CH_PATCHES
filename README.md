# MSFS CAT CH Patches

Patch Catalog and Patch Package sources for MSFS CAT CH. Each Package is published as a GitHub Release ZIP and listed in `manifest.json` with its SHA-256 checksum.

## Packages

- `gsx-pro-zh-cn`: GSX Pro Simplified Chinese localization.
- `fsrealistic-plus-zh-cn`: FSRealistic+ Simplified Chinese localization.

Package ZIP assets are generated from `packages/<patch-id>/payload/`. They must be released before the corresponding `published` Patch Catalog entry is pushed. Do not commit `dist/` artifacts.
