Quick Diagnosis

Common reasons FSR+ won't connect:

  • FSR+ service is not running
  • FSR+ port is in use by another application
  • Antivirus or security software is blocking FSR+

Is the Service Running?

Open Windows Task Manager (Ctrl + Shift + Esc), go to the Details tab, and look for:

fsrealistic-plus.exe

Tip: Click the "Name" column header to sort alphabetically, or use the search box if available.

Found it running?

Try a Different Port

  1. Close Microsoft Flight Simulator completely
  2. Open the port file:
    Community/rkapps-fsrealistic/html_ui/InGamePanels/FSRealistic/Port.js
  3. Change the number in var WS_PORT = 62137; to a different port, for example: var WS_PORT = 58297;
  4. Save the file
  5. Start MSFS and open the FSR+ in-game panel

Check Antivirus / Security Software

Some antivirus or security software may block FSR+ from running or listening for connections.

Option 1 (Recommended):

Add an exclusion in your antivirus/security software for:

Community/rkapps-fsrealistic/service/fsrealistic-plus.exe

Option 2 (Quick Test):

Temporarily disable your antivirus/security software to test if that's the issue.
(Remember to re-enable it afterwards!)

You may need to restart MSFS after making changes.

All Set!

FSR+ is connected. Enjoy your flight!
